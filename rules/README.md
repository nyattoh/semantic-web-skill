# Rule library — not implemented

These folders reserve the ownership boundaries defined by the [architecture](../docs/architecture.md). There are no executable or machine-readable rules here yet. The preserved specification is the current design baseline; completed normative rules will live here as the single source of truth.

Follow [rule authoring](../docs/rule-authoring.md). Each initial rule needs primary sources, applicability, stable ID, expected evidence, meaningful fixtures, and a human-review boundary. A folder's presence must never imply coverage or a passing check.
