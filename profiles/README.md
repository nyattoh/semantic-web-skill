# Profiles — design only

The specification proposes `baseline.json` and `editorial-lp-ja.json`; neither exists yet. Do not treat these names as loadable configuration.

The baseline should select implemented common rule IDs and allowed settings. The optional Japanese editorial profile may select project-appropriate copy/design preferences without converting them into universal standards or replacing legal review. Profiles must not duplicate normative rule text.

Implement and validate the [profile schema contract](../schemas/README.md) before adding runnable profiles. See [specification sections 3–4 and 14](../docs/product-spec.ja.md).
