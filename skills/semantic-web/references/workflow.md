# Workflow — draft

Read [specification section 11](../../../docs/product-spec.ja.md) for the two proposed modes. Select the smallest relevant set of modules and checks for the actual task. Existing-site review starts from observed code and behavior; new generation starts from content meaning and intended interaction.

The intended sequence is scope, applicability, current evidence, design or review, implementation when requested, actual checks, unresolved items, and handover. This starter does not execute that sequence automatically. No results should be marked passed merely because a document or SKILL.md was read.

For an implementation task, prefer one complete, testable rule-to-result path over many unchecked rule files. See [status and decisions](../../../docs/starter-status.md).
