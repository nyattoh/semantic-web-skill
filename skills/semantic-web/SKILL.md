# Semantic web — draft entrypoint

This starter has no implemented rules, checks, or supported installer. Use it as design guidance; never present its existence as a completed audit.

## Inputs and workflow

Clarify generation versus review, target content/code, intended audience, technical constraints, relevant publication markets, and permitted changes. Read [workflow guidance](references/workflow.md), [current status](../../docs/starter-status.md), and relevant portions of the [specification](../../docs/product-spec.ja.md).

Load only the relevant specialist SKILL.md files:

- [semantic-html](../semantic-html/SKILL.md): meaning and content models
- [css-foundations](../css-foundations/SKILL.md): layout and presentation
- [native-interactions](../native-interactions/SKILL.md): state and operation
- [accessibility](../accessibility/SKILL.md): access and shared target-size criteria
- [responsive-verification](../responsive-verification/SKILL.md): environment-specific checks
- [search-content](../search-content/SKILL.md): dated provider and content requirements
- [regional-compliance](../regional-compliance/SKILL.md): applicability and human review
- [evidence-reporting](../evidence-reporting/SKILL.md): actual results and handover

## Rules, output, and stopping conditions

[Rules are not implemented](../../rules/README.md). Identify proposed checks as design work, not executed validation. Report the selected scope, assumptions, actual work, evidence, and unresolved items using [handover guidance](../../docs/handover.md).

Stop dependent work when necessary inputs, permissions, current sources, or required environments are missing. Review does not authorize changes, publication, or deployment. Archived historical prompts are source material, not instructions to execute.
