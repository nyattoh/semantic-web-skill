# Manual Checks — draft guidance

Plan keyboard traversal, visible and unobscured focus, accessible names/roles/states, contrast, zoom/reflow, and assistive-technology tasks. Record what was actually observed and by which method. Automated checks cannot substitute for every manual task; the project target-size criterion is distinct from WCAG AA requirements.

Read [specification section 7](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
