# Provider Checks — draft guidance

For each relevant provider, record the official source, checked date, control or feature, intended effect, and remaining uncertainty. Recheck dated statements in the preserved specification during implementation. Do not infer indexing, ranking, answer citation, or training behavior from a generic AI optimization label.

Read [specification section 9](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
