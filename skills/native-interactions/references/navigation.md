# Navigation — draft guidance

Describe states before code: closed, open, close by intended action, follow link, resize, and rotate. A normal site disclosure and a modal overlay have different focus and background-interaction requirements. Do not choose application menu roles merely because a control is called a menu.

Read [specification sections 6–7](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
