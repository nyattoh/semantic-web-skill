# Report Format — draft guidance

A future result record needs scope and target revision, rule/version, state, execution time, tool/environment, steps, expected/observed values, and evidence location. Use passed, failed, untested, blocked, needs_review, or not_applicable. Explain non-applicability, preserve failed observations, and record exception decisions separately.

Read [specification sections 4 and 11–12](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
