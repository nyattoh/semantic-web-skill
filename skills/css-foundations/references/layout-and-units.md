# Layout And Units — draft guidance

Review intrinsic sizes, overflow sources, text growth, and cascade before prescribing layout. Media-query relative units do not inherit a changed root font size in the simplistic way assumed by the old source prompt. Use input capabilities for hover decisions; preserve keyboard focus and reduced-motion needs.

Read [specification sections 6–7](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
