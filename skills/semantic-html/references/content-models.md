# Content Models — draft guidance

Resolve element placement against the current HTML Standard and the actual context. A parser or validator can establish some structural constraints, but cannot establish all content meaning. Record source sections and distinguish project conventions from conformance requirements.

Read [specification section 5](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
