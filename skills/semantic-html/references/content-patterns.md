# Content Patterns — draft guidance

Choose ordered collections, unordered collections, or name/value associations based on content. FAQ, testimonials, images, tables, and forms need contextual choices; visual card styling does not itself justify article or section. Keep historical rigid wrappers and element substitutions out of the shared baseline.

Read [specification section 5](../../../docs/product-spec.ja.md) for the design baseline. This guide is not a tested implementation or an independent normative rule source. Implement owned rules and real fixtures before claiming automated support.
