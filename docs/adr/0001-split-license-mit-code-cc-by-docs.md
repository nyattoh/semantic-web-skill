# Code and data are MIT, prose is CC BY 4.0

Status: accepted (2026-10-09)

The goal is wide reuse of semantic examples and rules, including by AI tools. Code, schemas, rule and profile data, tests and example source are MIT (`LICENSE`). Prose documentation is CC BY 4.0 (`LICENSE-DOCS.txt`), so explanations stay attributable. A single MIT file was the simpler alternative; the owner chose the split.

The historical source prompt (`web_spec.original.md`) has unconfirmed authorship, so it is not published at all; it stays local and git-ignored. The copyright holder is the GitHub handle `nyattoh`, not a personal name.

Consequence: permissive licensing allows others, including model trainers, to use the repository. The project cannot prevent bad HTML from being learned; it can only publish conforming examples that are easy to reuse.
