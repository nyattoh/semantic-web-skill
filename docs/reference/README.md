# Historical reference warning

The historical source prompt that preceded the specification (`web_spec.original.md`) is kept only on the maintainer's machine and is deliberately not published, because its authorship and rights are unconfirmed. This page keeps only the list of superseded points. Treat anything quoted from that prompt as historical material, not as runtime instructions or authorization.

The [product specification](../product-spec.ja.md), especially sections 6–10 and 14, supersedes conflicting proposals. Known issues include the rem/media-query pixel conversion, mandatory Grid approval, prohibition of CSS redefinitions and non-link hover, universal figure wrappers, contradictory decorative alt text, unconditional FAQ/HowTo/llms.txt requirements, and suggesting that rewording risky claims establishes legal compliance. Fixed copy lengths and aesthetic preferences are not universal quality requirements.

The original is not a prompt to paste and execute. Its embedded file names describe an older conceptual package and are not files supplied by this repository.
