# semantic-web-skill

Web制作・改善の品質を分野別に扱うスキル集の、実装開始用ファイル一式です。

**現在は仕様・文書・スキル草案のスターターです。完成済み・動作検証済みの配布版ではありません。** 梱包基準日は2026年10月8日UTC。仕様書の日付は日本時間の2026年10月9日をそのまま保持しています。公開先は <https://github.com/nyattoh/semantic-web-skill> です。

[English](README.md) / [仕様書全文](docs/product-spec.ja.md) / [実装状況](docs/starter-status.md) / [構成](docs/architecture.md)

## 入っているもの

- 仕様書の完全版。元ファイルとバイト単位で同一です
- 入口スキル1個と専門スキル8個のSKILL.md草案、および短い参照ガイド
- 英日README、貢献方法、引き渡し基準、GitHub公開の手動手順
- ルール・スキーマ・プロファイル・サンプル・テストの配置先と設計メモ
- 旧制作プロンプトで置き換えた点の要約（原文は権利未確認のため非公開）

## 使い始める順番

1. [仕様書](docs/product-spec.ja.md)と[未決定事項](docs/starter-status.md)を確認する。
2. [入口SKILL.md](skills/semantic-web/SKILL.md)から、必要な専門分野だけ読む。
3. まず一つのルール、合格・不合格・境界の試験素材、実際の検査と結果記録をつなげて実装する。
4. 実際に確認した導入方法と対応環境だけを互換性資料へ追記する。

AIへ渡す依頼の例：

> このリポジトリは未検証のスターターです。仕様書を確認し、HTMLの意味構造に関するルールを一つ、合格・不合格・境界の試験素材とともに実装してください。実際に実行した検査、結果、未確認事項を報告してください。

参照先はリポジトリ内の相対リンクです。検討中はフォルダー一式を維持してください。個々のスキルだけを取り出す導入方法や、各エージェントでの実行は未検証です。

## まだ入っていないもの

実行可能な品質監査、JSONスキーマ、ルールデータ、デモサイト、テストランナー、CI、インストーラー、地域別の検証済みルールパックは未実装です。機械的な合格判定や、アクセシビリティ・検索順位・法令適合の保証はありません。
